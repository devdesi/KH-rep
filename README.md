# Kartikeya Multispeciality Hospital

Marketing website for Kartikeya Multispeciality Hospital, located at 7/34, Main Bazar, Divili, Pithapuram, Kakinada. The site introduces the hospital, its managing director Dr. Pasupuleti Santhosh Kumar, its three specialities (General Medicine, Obstetrics & Gynaecology, and Paediatrics), and how to reach or visit the hospital.

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React 19 + TanStack Router)
- Vite 7
- Tailwind CSS 4
- TypeScript
- Deployed on Netlify

## Running locally

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:3000`.

To build for production:

```bash
npm run build
```
